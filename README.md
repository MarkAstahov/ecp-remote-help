# Удалённая помощь с ЭЦП

Статическая страница-визитка для услуги удалённой помощи с ЭЦП, КриптоПро, токенами, браузерным плагином и ЭДО.

**Публичный сайт:** https://markastahov.github.io/ecp-remote-help/

## Что это

- Одна страница с описанием услуги, ценами и контактами.
- Связь только по электронной почте: `ecpnavigator@yandex.ru`.
- Рабочее время: с 9:00 до 18:00 каждый день.
- Цены: 2 000 ₽ за удалённый сеанс до 60 минут; 3 000 ₽ за настройку рабочего места с нуля до 90 минут.
- Нет формы, телефона, мессенджеров, аналитики и серверной части.
- Нет ссылки на основной сайт и демо.

## Безопасность

- В репозитории нет `.env`, ключей, токенов, баз данных, логов и бэкапов.
- На странице нет форм и сбора персональных данных.
- Публикуются только рабочий email и деловые реквизиты ИП.
- Банковские реквизиты, домашний адрес и личный телефон не публикуются.
- Для страниц задан строгий `Content-Security-Policy`.

Подробнее — в [SECURITY.md](SECURITY.md).

## Локальный просмотр

```powershell
python -m http.server 8090 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8090/`. Также можно открыть `index.html` напрямую или использовать `start.cmd`.

## Файлы

- `index.html` — основная страница;
- `styles.css` — оформление;
- `app.js` — копирование email;
- `offer.html` — условия оказания услуг;
- `privacy.html` — политика обработки данных;
- `sitemap.xml`, `robots.txt` — индексация;
- `start.cmd` — локальный просмотр.

## Публикация

Сайт размещён на GitHub Pages из ветки `main`; статика отдаётся из корня репозитория. `CNAME` не используется, пока домен не подключён.
